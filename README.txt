EYМEN AI - ilk çalışan PWA prototipi
1) ZIP'i açın.
2) İçindeki dosyaları GitHub deposunun ana dizinine yükleyin.
3) GitHub > Settings > Pages > Deploy from a branch > main / root seçin.
4) Oluşan HTTPS adresini Samsung Internet veya Chrome ile Note 9'da açın.
5) Tarayıcı menüsünden Ana ekrana ekle / Uygulamayı yükle seçin.
6) Mikrofon iznini verin. Ses tanıma tarayıcı ve internet desteğine bağlıdır.

Bu sürüm: saat, sesli komut, hesap makinesi, kronometre, sayaç, yerel not ve web kısayolları.
Not: Bu bir PWA prototipidir; henüz yerel Android APK değildir. Fener/Bluetooth gibi sistem kontrolleri web sürümünde doğrudan kontrol edilmez.
